# Agent-to-Human Task Requests

Purpose: This document describes the process for requesting tasks from the human agent.
It is intended to be read by both the human agent and the user.
Once you have read this document, you can request a task by sending a message to the human agent with the following format:

```format
Task: <task description>
Details: <additional details or context>
```

## Outstanding Requests

Outstanding requests are tasks that have been submitted to the human agent but have not yet been completed.
The human agent will review these requests and provide updates on their status.
Sort the requests by priority, with the highest priority tasks at the top of the list.
